I download OpenStreetMap tiles in batch with two-tier caching. I use OSMTileCache to avoid re-downloading tiles already in memory or on disk. I support both synchronous (downloadAll) and asynchronous (downloadAllInBackground + waitForCompletion) modes. Use me to pre-fetch a batch of tiles before rendering so the UI is not blocked tile-by-tile. Each tile is checked against the cache first; only truly new tiles hit the OSM server.
